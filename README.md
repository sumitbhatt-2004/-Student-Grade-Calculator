# Student Grade Calculator 🎓

A Python-based application designed to take student marks, validate the input, calculate grades using `if-elif-else` logic, and display encouraging messages[cite: 2]. This project is part of Week 2 hands-on practice for Python & Data Science internships[cite: 1, 2].

---

## 🚀 Features
- **Interactive Input:** Takes student name and marks as input.
- **Input Validation:** Uses a `while` loop and error handling (`try-except`) to ensure marks are strictly between `0` and `100`[cite: 2].
- **Automated Grading:** Evaluates performance and assigns grades (`A`, `B`, `C`, `D`, `F`)[cite: 2].
- **Encouraging Feedback:** Displays personalized motivating messages based on performance[cite: 2].

---

## 📊 Grading Logic Reference
| Marks Range | Grade | Performance Status |
| :--- | :---: | :--- |
| **90 - 100** | A+ / A | Outstanding / Excellent[cite: 4] |
| **80 - 89** | B | Great job[cite: 4] |
| **70 - 79** | C | Good effort[cite: 4] |
| **60 - 69** | D | Fair performance[cite: 4] |
| **0 - 59** | F | Needs improvement / Retry[cite: 4] |
